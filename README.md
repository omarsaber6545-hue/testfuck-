# بوت الألعاب والبنك المتطور (Discord Games & Bank System) 🎮🏦

بوت ديسكورد شامل واحترافي مستوحى من بوتات الألعاب والبنك الشهيرة (مثل فيزبو Fezbo)، مبني بأحدث إصدارات **Discord.js v14** بتصميم عصري راقٍ (**Components V2**) بدون كثرة إيموجي مشتتة، وبدون أي اعتماد على سلاش كوماندز (Prefix & Chat text-based فقط)، وبدون داشبورد، وبدون أي IDs مثبتة داخل الملفات.

---

## 🌟 أبرز مميزات النظام

1. **بدون سلاش كوماندز (Zero Slash Commands):**
   - يعمل بالكامل عبر البريفكس الافتراضي `!` و `-` أو بكتابة اسم اللعبة/الأمر مباشرة في الشات (مثل `روليت`، `خمن`، `رصيد`، `سلوت`).
2. **عجلة روليت متحركة احترافية (Animated Wheel GIF):**
   - عند كتابة `!روليت` أو `-روليت` يُفتح لوبي تفاعلي بأزرار (انضمام، انسحاب، تدوير).
   - يتم توليد صورة GIF متحركة حقيقية للعجلة وهي تدور وتتباطأ تدريجياً بفيزياء دوران واقعية.
   - تظهر أسماء اللاعبين على شرائح العجلة، ويتوسط العجلة أفتار العضو الفائز.
3. **نظام الوظائف بالذهب (`data/jobs_config.json`):**
   - ملف مخصص يحتوي على الوظائف وأسعارها بالذهب النادر ورواتبها المزدوجة (كاش + ذهب).
   - يمكن التقديم والشراء بالذهب مباشرة عبر أمر `وظائف`.
4. **لعبة خمن بمكافأة 3 ذهب:**
   - مسابقات وألغاز وأرقام تفاعلية في الشات، الفائز يحصل تلقائياً على **3 🪙 ذهب** + كاش ونقاط فوز!
5. **ماكينة السلوتس المتطورة:**
   - تمنح عشوائياً أرباحاً بين **3 إلى 6**، مع فرصة حظ نادرة (5%) تمنح جاكبوت **5 أو 10 ذهب**!
6. **لعبة مافيا ديسكورد الجماعية الكاملة:**
   - تدعم 4 لاعبين فأكثر مع توزيع الأدوار سراً (مافيا، طبيب، محقق، مواطنون) ودورات ليل ونهار وتصويت تفاعلي بالأزرار والقوائم.
7. **نظام نقاط الألعاب والمتصدرين:**
   - كل فوز في أي لعبة يمنح اللاعب نقاطاً موثقة.
   - أوامر عرض النقاط والرتبة: `نقاط` و `توب-نقاط`.
8. **إدارة الرومات والرتب المسموحة ديناميكياً:**
   - تحديد رومات البنك المسموحة: `اضف-روم-بنك`، `ازالة-روم-بنك`، `رومات-البنك`.
   - تحديد رومات الألعاب المسموحة: `اضف-روم-العاب`، `ازالة-روم-العاب`، `رومات-العاب`.
   - تحديد رتب مسؤولي الألعاب: `اضف-رتبة-العاب`، `ازالة-رتبة-العاب`، `رتب-العاب`.
9. **صلاحيات حصرية للأونرز (Bot Owners):**
   - أوامر إعطاء وإزالة الذهب، الكاش، النقاط، وتصفير الحسابات لا يمكن استخدامها إلا من قبل الأونرز فقط.

## 🚀 طريقة التشغيل السريعة

### 1. المتطلبات
- بيئة **Node.js v18** أو أحدث.

### 2. إعداد ملف البيئة `.env`
قم بفتح ملف `.env` وضع توكن البوت ومعرف الأونر:
```env
DISCORD_TOKEN=your_bot_token_here
CLIENT_ID=your_client_id_here
OWNER_IDS=your_discord_id_here
```

### 3. تشغيل البوت
```bash
# تشغيل البوت في بيئة الإنتاج
npm start

# أو تشغيله مع التحديث التلقائي أثناء التطوير
npm run dev

# لتشغيل فحص الاختبارات الشاملة للتأكد من سلامة النظام
npm test
```

## 📋 جدول الأوامر الكامل

### 1. أوامر البنك والاقتصاد (في رومات البنك المسموحة)
| الأمر | الوصف |
| :--- | :--- |
| `رصيد` أو `الرصيد` [@user] | عرض بطاقة الحساب (الكاش، البنك، الذهب، الوظيفة، الثروة) مع أزرار سريعة |
| `ايداع <مبلغ / الكل>` | إيداع الكاش من المحفظة إلى حساب البنك |
| `سحب <مبلغ / الكل>` | سحب الأموال من حساب البنك إلى المحفظة |
| `تحويل [@user] <مبلغ>` | تحويل كاش إلى عضو آخر (مع احتساب ضريبة 5%) |
| `تحويل ذهب [@user] <كمية>` | تحويل الذهب النادر إلى عضو آخر بدون ضرائب |
| `وظائف` أو `وظيفة` | استعراض قائمة الوظائف وأسعارها بالذهب ورواتبها والشراء |
| `راتب` أو `عمل` | استلام راتب الوظيفة الحالية (كاش + ذهب) وفق مهلة العمل |
| `هدية` أو `يومي` | استلام الهدية اليومية وزيادة الستريك والذهب |
| `نهب` أو `سرقة` [@user] | محاولة سرقة محفظة عضو آخر مع احتمال الغرامة |
| `حماية` أو `درع` | شراء درع حماية لمدة 24 ساعة ضد محاولات السرقة |
| `قرض [مبلغ]` | طلب قرض بنكي طارئ بفائدة 10% |
| `سداد` | تسديد كامل القرض البنكي القائم |
| `بقشيش` | طلب إكرامية نقدية صغيرة كل 15 دقيقة |
| `كشف [@user]` | فحص السجل المالي والجنائي وحالة الحماية والقروض |
| `الوقت` | عرض عدّاد المهلات المتبقية لجميع أوامر البنك |

| الأمر | الوصف |
| :--- | :--- |
| `!روليت` أو `روليت` | بدء عجلة الروليت الجماعية المتحركة (GIF) وتتويج الفائز بالنقاط والذهب |
| `!مافيا` أو `مافيا` | بدء لعبة المافيا الجماعية التفاعلية (أدوار ليل، نهار، وتصويت) |
| `خمن` | مسابقة تخمين سريعة بالشات تمنح الفائز **3 🪙 ذهب** ونقاط فوز |
| `سلوت [رهان]` | ماكينة السلوتس تعطي من 3 إلى 6، مع فرصة حظ نادرة تمنح **5 أو 10 ذهب** |
| `عواصم` | مسابقة عواصم الدول بالشات مع جوائز كاش ونقاط |
| `أعلام` | مسابقة معرفة أسماء الدول من أعلامها |
| `فكك` | تفكيك حروف الكلمة العربية بمسافات |
| `ركب` | تجميع الحروف المعطاة لتكوين كلمة صحيحة |
| `أسرع` | مسابقة أسرع شخص يكتب الجملة المعروضة |
| `كت-تويت` أو `كت` | بطاقات نقاشية وتفاعلية بأزرار للمشاركة |
| `xo [@user]` | مباراة إكس أو تفاعلية بشبكة أزرار 3×3 وجوائز فوز |
| `كراش [رهان]` | صاروخ بمضاعف يرتفع تدريجياً مع زر سحب الأرباح قبل الانفجار |
| `الغام [رهان]` | حقل ألغام تفاعلي بالأزرار لاكتشاف الجواهر وسحب الكاش |
| `نرد [رهان]` | رمي النرد وتحدي الحظ ضد البوت |
| `حجر` أو `حجر-ورقة-مقص` | لعبة حجر ورقة مقص بأزرار تفاعلية |
| `حساب` أو `رياضيات` | حل مسائل حسابية سريعة في الشات |
| `نقاط` [@user] | عرض إجمالي نقاط الألعاب والترتيب في السيرفر |
| `توب` / `توب-ذهب` / `توب-نقاط` | لوائح المتصدرين في السيرفر |

| `اضف-روم-بنك [#channel]` | إضافة روم إلى قائمة رومات البنك المسموحة |

| `اضف-اونر [@user]` | تعيين عضو كأونر للبوت في السيرفر |
| `ازالة-اونر [@user]` | إزالة صلاحيات الأونر من عضو |
| `الاونرز` | عرض قائمة الأونرز المسجلين |

## ⚙️ تخصيص الوظائف (`data/jobs_config.json`)
يمكنك فتح ملف `data/jobs_config.json` والتعديل على الوظائف أو إضافة وظائف جديدة بكل سهولة:
```json
{
  "id": "programmer",
  "name": "مبرمج ومطور أنظمة",
  "description": "تطوير البوتات والحلول التقنية",
  "priceGold": 85,
  "reqLevel": 12,
  "cooldownMinutes": 75,
  "salaryCashMin": 6500,
  "salaryCashMax": 9500,
  "salaryGold": 9
}
```
- `priceGold`: سعر شراء والتعيين بالوظيفة بعملة الذهب.
- `reqLevel`: المستوى المطلوب للتأهل للوظيفة.
- `cooldownMinutes`: مهلة استلام الراتب بالدقائق.
- `salaryCashMin` & `salaryCashMax`: نطاق الراتب بالكاش.
- `salaryGold`: الراتب الإضافي المضمون بالذهب.
